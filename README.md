# Visor_3D_Dress-Magic

Objetivo del Juego: El juego está dirigido principalmente a un público infantil, especialmente niñas que disfrutan de la moda, vestir personajes y crear diferentes combinaciones.

Está pensado para ser un juego sencillo y fácil de entender, dirigido a jugadores que buscan una experiencia de creatividad, personalización y descubrimiento, el juego pertenece al tipo de juegos de moda y personalización de personajes, pero busca diferenciarse mediante las combinaciones mágicas que permiten descubrir y desbloquear nuevas prendas y accesorios.
